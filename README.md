### ▌ HOW I WORK

I help boards, audit committees and CXOs strengthen governance, risk, finance, internal audit and regulatory compliance.

Working method, from practice and public work:

1. Start from the source document — Act, circular, policy, SOP — not from a remembered checklist.
2. Atomise numbered clauses and conditions before designing a control or a register.
3. Separate extracted text from proposed mapping. Keep an evidence trail.
4. Use agents where they raise speed and repeatability. Keep a human desk on judgment, exceptions and sign-off.
5. Ship the artefact the control function can run: register, calendar, workflow UI, workbook — with demo labels when the data is synthetic.

Domain concentration visible on this account: SEBI-class listed-company compliance, policy/SOP extraction, ICOFR-style control thinking, internal tools for operations.
